# Portfolio Website

Personal portfolio site for Avisek Dalal, built with React and Vite.

## Installation

```bash
npm install
```

## Local Development

```bash
npm start
```

Starts the Vite development server and opens the site locally.

## Build

```bash
npm run build
```

Outputs static files to the `dist` directory.

## Preview Production Build

```bash
npm run preview
```
